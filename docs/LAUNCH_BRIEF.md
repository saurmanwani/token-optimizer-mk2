# ContextProof Launch Brief

## Headline

Before you compress context, prove what the model can afford to forget.

## One-line pitch

ContextProof is a local-first inspector that shows where coding-agent context
goes and verifies context policies against explicit evidence-preservation
invariants.

## Launch demo

1. Inspect `examples/sample-trace.json`.
2. Show the context bill of materials and conservative recommendations.
3. Run the stale-output intervention with `--json`.
4. Retrieve a cleared fatal error byte-for-byte from its SHA-256 handle.
5. Run the 120-case benchmark.
6. Open the report UI and point to the limitations before the headline number.

## Proof points

- Local inspection with no provider key
- Advisory by default
- Recoverable stale-output clearing
- Model/counting-method disclosure
- Machine-readable benchmark results
- Public benchmark and security contracts

## Claims permitted at launch

- “120/120 bundled synthetic cases preserve declared evidence invariants.”
- “The bundled policy removes 25.62% of active synthetic context.”
- “Removed benchmark evidence is byte-exact recoverable.”

## Claims not permitted

- “No quality loss”
- “Makes agents 25.62% cheaper”
- “Works on every model or agent”
- “Production ready”
- “Real-agent task success is unchanged”

## Reputation campaign

Publish three connected artifacts:

1. The State of Coding-Agent Context report
2. A five-minute teardown and live recovery demo
3. The decision case study explaining why the prompt-optimizer product was
   killed

Use one argument consistently: context optimization needs an evidence standard,
not another universal savings percentage.

## Design-partner ask

Recruit five teams willing to run the local inspector and share aggregate,
redacted metadata. Ask for their highest-cost agent workflow, current compaction
symptoms, acceptable evidence-loss threshold, and one reproducible task suite.
